how to start kubernetis:

1. Start Docker. minikube runs inside Docker.

sudo systemctl start docker
2. Start the cluster.

minikube start
minikube status        # host, kubelet and apiserver should all say "Running"
3. Build the image inside minikube's Docker. Your k8s.yaml uses imagePullPolicy: Never, so the image has to exist inside minikube, not just on your laptop.

eval $(minikube docker-env)
docker build -t portfolio .
4. Deploy.

kubectl apply -f k8s.yaml
kubectl get pods       # wait until STATUS is "Running"
5. Open the site.

minikube service portfolio
To stop everything afterwards:

minikube stop
sudo systemctl stop docker docker.socket


restart kube
kubectl rollout restart deployment portfolio
